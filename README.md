# A-Insight · A股主力资金智能分析系统 v2.1

> 只分析，不交易，不预测 —— 专业级A股资金流向分析终端

## 核心功能

### 📊 实时资金分析
- **5534只A股全市场覆盖** — 主力/超大单/大单/中单/小单资金流
- **30个申万一级行业** — 按华泰证券标准分类，聚合496细分为30大类
- **行业成分股下钻** — 点击任意行业，展开全部成分股资金排序
- **资金流比例条** — 按实际比例渲染，一眼看出资金集中度

### 🔬 华泰多因子选股
- **7因子模型** — 动量1M/3M、波动率、换手率、规模、资金流、均线偏离
- **827天历史回测** — IC分析 + IC_IR加权优化
- **反转策略** — A股特有的均值回归效应，买跌不买涨
- **每日9:00自动计算** — 无需手动操作
- **500只股票覆盖** — 随数据积累持续扩大

### 🤖 AI分析
- **DeepSeek V4 Pro市场日报** — 识别出货/诱多/背离信号
- **个股AI分析** — 资金面 + 成本区 + 建仓/出货判断

### 🎯 个股推荐
- **主力净买TOP30** — 今日大资金在买什么
- **疑似建仓** — 主力买入+涨幅小=悄悄吸筹
- **疑似出货** — 涨了但主力在卖=边拉边跑

## 技术栈
- Python 3.11 + FastAPI + SQLAlchemy + PostgreSQL
- Vue 3 + ECharts (单文件SPA)
- 东方财富 push2 API + AkShare
- DeepSeek V4 Pro

## 快速启动
```bash
pip install -r requirements.txt
export DEEPSEEK_KEY=your_key_here
python3 app.py
# http://localhost:8100
```
